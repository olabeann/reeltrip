B-01 홈과 링크 입력

화면 열기

입력

규칙

행동·전이

상태

규칙

B-24 메이트 가능 일정

화면 열기

입력
availability, blackout_dates
규칙
실서비스 날짜별 시간 슬롯과 예약의 원자적 잠금 필요. 데모는 요청일 수락 가능 여부만 저장.
행동·전이
가능 / 불가 토글 저장
상태
가능 / 불가 / 예약 일정 충돌
인수 기준
불가 설정이면 신규 함께할 여행 제안하기 차단. 기존 확정 예약을 자동 취소하지 않음.

gross, fee_rate, refund, payout_status
규칙

행동·전이
미납 수수료 → guide-fee
상태
예정 / 보류 / 지급 검토 가능 / 지급 완료
인수 기준
고객 금액·환불과 정산 계산 일치. 실제 송금 없음 표시.

B-26 운영 대시보드

집계 이벤트, 운영 큐

행동·전이
admin-places / admin-support / admin-guides·admin-bookings
상태
예시 집계 / 처리 대기

완료되지 않은 실험 데이터가 실제 매출로 표시되지 않음.

B-27 장소 오류 검수

place_id, correction_reason
규칙
원본 추출값과 수정값 모두 보관. 기존 확정 투어에는 자동 적용하지 않고 변경 검토 큐로 전달.

검수 상태 변경
상태
미검수 / 승인 / 반려

B-28 문의와 데이터 요청 관리

ticket_id, status, response_note

로컬 문의 상태 업데이트
상태
없음 / open / resolved
인수 기준
미접수 문의를 실제 문의로 표시하지 않음. 완료 상태가 저장됨.

B-29 메이트 자격 심사

화면 열기

입력
verification_flags, review_note
규칙

검토 체크 후 승인 또는 보완
상태
pending / needs_info / approved / suspended
인수 기준
필수 체크 없이 승인 불가. 프로토타입 자격 자료는 가상 예시이며 진짜 검증이 아님.

B-30 예약·환불 운영

화면 열기

규칙

행동·전이
취소 요청 검토 → 모의 환불 완료
상태
확정 / 취소 요청 / 환불 처리 중 / 환불 완료
인수 기준
취소 요청 없는 예약 환불 승인 차단. 환불액은 결제액 이하. 정산 화면도 갱신.

B-31 알림

B-33 매칭 수수료 결제
