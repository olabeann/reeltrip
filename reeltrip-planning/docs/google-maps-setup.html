Google 지도 · 기획 이미지와 실제 연동

v1.8 · 방문 순서 연결선

기획 이미지 모드에서 선택한 장소를 방문 순서대로 연결합니다. 일정의 위·아래 버튼으로 순서를 바꾸면 사진 핀 번호, 연결 구간, 방향 화살표가 함께 갱신됩니다. 날짜별 일정과 저장 상태를 그대로 사용합니다. 0~1곳이면 연결선이 없으며, 좌표가 없거나 이미지 범위 밖인 중간 장소는 건너뛰어 연결하지 않습니다. 표시한 선은 직선으로 표현한 방문 순서이며 실제 도보·차량 길찾기 경로가 아닙니다. 실시간 SDK 연결선은 추후 개발 범위입니다.

v1.7 · API 키 없이 기획 검토

현재 기본 모드는 실제 Google Maps 화면을 캡처한 정적 이미지와 앱의 사진 핀입니다. 서비스에서 핀 선택·날짜 변경·장소 순서 변경을 체험할 수 있습니다. 배경의 확대·이동은 지원하지 않습니다. Google 로고와 지도 데이터 ©2026 TMap Mobility 표기를 유지합니다. 사진 핀은 기획용 위치 주석이며 정확한 입구·길찾기를 보장하지 않습니다.

캡처: 2026-11-17, 성수·서울숲 Google 지도. 원본 화면 640×600을 저장하고 앱에서는 검색·계정 영역을 제외한 아래 640×490 영역만 CSS로 표시. 가장자리 핀은 번호가 잘리지 않도록 표시 위치를 보정. 지도 콘텐츠 자체는 보정하지 않았고, 앱에서 별도 사진 핀을 겹쳐 표시합니다. 이 캡처는 사진들의 CC 라이선스와 별개입니다.

assets/maps-config.js에서 mode=auto이면 키가 없을 때 검토 이미지, 키가 있으면 실제 Google 지도 SDK를 사용합니다. mode=review이면 키가 있어도 검토 이미지를 사용합니다.

실제 연동 준비 · v1.6 기록

두 앱은 같은 Google Maps JavaScript API 연결 코드를 사용합니다. 예시 지도 그림과 픽셀 기준 핀은 제거했습니다. 현재 API 키가 없어 실제 지도 표시 검증은 대기 중입니다.

개발자가 설정할 항목

  1. assets/maps-config.js의 apiKey에 브라우저용 키를 설정합니다. Maps JavaScript API 활성화와 결제 계정 연결 여부를 확인합니다.
  2. 키의 웹사이트 제한에 실제 서비스 도메인과 필요한 localhost 개발 주소만 허용하고 API 제한을 적용합니다. 서버 비밀 키는 넣지 않습니다.
  3. mapId를 프로젝트의 지도 ID로 교체합니다. DEMO_MAP_ID는 개발 확인용 기본값입니다.
  4. file:// 대신 HTTP 로컬 서버나 HTTPS 배포 주소로 엽니다. 프로젝트 폴더에서 python3 -m http.server 8765 --bind 127.0.0.1 실행 후 http://127.0.0.1:8765/이전 경로/index.html 또는 app/index.html을 엽니다.

반영한 동작

실제 Google 기본 지도, 확대·축소·이동, 위경도 기반 사진·번호 마커, 핀 선택과 장소 카드 연결, 날짜 변경 시 해당 장소만 표시, 좌표 없는 장소의 별도 안내. Google 로고와 저작권 표시는 지도 SDK가 제공하며 가리지 않습니다. 실제 경로 데이터가 없으므로 가짜 도보 경로선은 그리지 않습니다.

장소 데이터 주의

서울숲은 공원 대표 좌표입니다. 카페와 상점은 Wikimedia 사진의 촬영 좌표로, 실제 매장 입구나 정확한 지점 확인이 완료된 데이터가 아닙니다. 광장시장 먹거리는 점포 좌표가 없어 핀에서 제외됩니다. 개발자의 추출 API가 반환하는 실제 지점 위경도·place_id로 교체해야 합니다. 이름·주소를 수정하면 이전 좌표는 무효화합니다.

검증 상태

키 미설정 안내, 외부 API 요청 방지, 좌표 없는 장소 제외, 위경도 전달과 번호 유지 단위 검증 완료. 실제 타일 로딩, API 권한·도메인 제한, 모바일 지도 제스처와 지도 위 마커 표시는 키 설정 후 서비스에서 추가 확인해야 합니다.
