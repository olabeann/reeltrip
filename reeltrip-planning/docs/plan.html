서비스 기획

영상과 직접 입력으로 장소를 모으고, 내 여행을 만든 뒤 현지 메이트의 제안을 비교하는 매칭 서비스다.

탭별 역할

  • 발견: 영상 링크로 장소 찾기 → 선택한 장소를 보관함에 저장. 바로 일정에 넣지 않는다.
  • 채팅: 여행 요청·메이트별 대화 목록. 제안 상세에서 상담을 시작하고 예약 후에도 이력을 유지한다. 최근 메시지·시각·상태·역할별 미읽음 표시. 종료된 대화는 읽기 전용. 실제 전송 없는 로컬 시제품.
  • 내 여행: 여행 생성 카드·간단한 저장한 장소 진입·다가오는 여행/지난 여행 목록. 여행 상세는 상단 정보 수정·전체 공유, 지도, 날짜별 일정 시트, 순서 번호와 거리 안내, ＋ 메뉴(저장한 장소·새 장소·메모)로 구성한다. 날짜별 메모를 저장하고 출발일 수정 시 모든 날짜를 함께 이동한다. 새 여행 생성·선택 후 상세 안에서 날짜·장소·순서·체류시간·메이트 요청을 관리한다. 여행별 일정은 분리 저장하고 장소 보관함은 공유한다. 일정에서 빼도 보관함에는 유지.
  • 메이트: 받은 제안 관리 / 자유 견적 받기. 자유 견적은 여행 지역·출발일·기간(당일~6박 7일)·인원으로 요청하며 장소 목록은 필요 없다. 내 여행에서는 날짜별 장소가 담긴 전체 여행으로 요청한다. 두 경로 모두 공개 요청 후 복수 제안을 비교·선택한다.
  • 마이: 프로필 편집, 진행 중인 여행과 활동 바로가기. 설정 아이콘 안에 언어·모드 전환, 도움말·약관·데이터 관리.

확정 흐름

여행 공개 → 메이트들의 일정·가격 제안 → 여행자 선택·예약 요청 → 메이트 확정 대기 → 메이트가 10% 매칭 수수료 결제 → 예약 확정 → 현장에서 여행비 전액 현금 직접 지급.

240,000원 여행이면 메이트는 플랫폼에 24,000원을 선결제하고, 여행자는 메이트에게 240,000원을 현금으로 직접 지급한다. 플랫폼은 여행비를 수납·송금하지 않는다.

현재 구현 범위

고객·메이트 동일 앱, 운영자는 별도 웹. 한국어·영어 로컬 시제품. 여러 여행·1개 활성 공개 요청을 유지하며, 내 여행 전체 일정 또는 자유 견적 요청을 공개한다. 기간과 요청 유형은 제안·예약까지 스냅샷으로 보존한다. 복수 제안과 가이드별 재발행은 지원한다. 실제 영상 분석·인증·DB·PG·푸시·다중 사용자 동기화는 미구현이다.
