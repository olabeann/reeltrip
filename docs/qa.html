REELTRIP / DOCUMENTATION

검증 기준

코드 검사는 브라우저·기기 시각 검증이나 실제 서버 통합 검증을 대체하지 않는다.

  • node tools/tests/startup_checks.cjs: 전체 entry script 초기화·기존 저장 데이터 로드.
  • node tools/tests/navigation_checks.cjs: 한영 경로·닉네임·복수 제안·현금 매칭 상태 전이.
  • node tools/tests/matching_routes_checks.cjs: 장소 저장 분리·두 요청 경로·다일 견적·예약 기간 보존.
  • node tools/tests/access_checks.cjs: 역할별 시연 접근.
  • node tools/tests/google_map_checks.js: 지도 폴백·좌표.
  • python3 tools/tests/static_checks.py: 문서·경로·화면 추적성.
  • 프로젝트 루트에서 node tools/tests/tower_seed_checks.cjs: 기존 데이터 업그레이드.

출시 전 실제 인증·서버·PG 실패/중복/철회 경합·푸시·기기별 화면·접근성·운영 정책을 별도 검증한다.

여행 지도 핀 전체 표시: 원인·구현 기준·인수 확인 항목
