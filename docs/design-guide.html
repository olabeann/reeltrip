rt-feedback-card--error / rt-feedback-card--compact: 실패 안내는 흰 배경·중립 테두리에 작은 빨간 warning 아이콘으로 표시합니다. 32px 아이콘 영역과 본문을 가로 배치하고 내부 여백 16px·열 간격 12px·제목 16px·본문 13px·줄높이 1.5를 사용합니다. 카드 전체를 빨갛게 채우지 않습니다. rt-payment-deadline은 14px 기한·12px 시간대 안내입니다. 재시도는 기본 파란 버튼을 사용합니다.
