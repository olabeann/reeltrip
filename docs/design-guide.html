실제 UI

앱과 동일한 렌더링 코드와 CSS를 사용합니다. 화면과 상태를 선택하고 버튼을 눌러 팝업·선택·입력 상태를 확인할 수 있습니다.

새 창에서 보기 ↗

미리보기의 저장 공간은 실제 앱과 분리됩니다. 시제품이며 실제 인증·결제·메시지 전송은 연결되지 않았습니다. 화면을 조작한 뒤 초기화하면 선택한 예시 상태로 돌아갑니다.

컴포넌트 확인 방법
  • 소셜 버튼: 회원가입 화면의 Google·카카오·네이버 버튼을 확인합니다.
  • 장소 메뉴: 여행 일정 화면에서 장소 오른쪽 더보기를 누릅니다.
  • 빈 상태·실패·비활성: 화면·상태 목록에서 해당 상태를 선택합니다.
  • 설정 팝업: 설정 화면에서 해당 항목을 누릅니다.
  • 운영 웹: 화면·상태 목록에서 운영 화면을 선택합니다. 새 창에서 데스크톱 너비로 확인할 수 있습니다.
