개발 설계

원본: assets/app.js, catalog.js, access.js, revenue.js. 영어는 i18n/build_english.py로 생성한다. 기존 B-* ID와 localStorage 키는 내부 호환성을 위해 유지한다.

  • library: 장소 보관함. board/days: 날짜별 일정.
  • request: 공개 여행 스냅샷. proposals: 메이트별 견적 배열. quote: 현재 상세 선택 제안.
  • booking: 선택 제안 스냅샷, feeRate=0.1, feeAmount, feeStatus, paymentMethod=cash, cashStatus.
  • 프로필·읽음 상태·닉네임 디렉터리는 현재 로컬 저장이다. 서버 인증·소유권·개인정보 보호는 별도 구현이다.

서버 연결 계약

여행자 예약 요청은 awaiting_mate_fee. PG 서버 응답·서명 웹훅의 금액/통화/주문/선택 메이트 ID를 대조한 후 confirmed. 클라이언트 성공 값만으로 확정 금지. 서버 가격 스냅샷·트랜잭션·결제 멱등성·취소와 결제 경합 보상 처리를 구현한다. 닉네임 canonical UNIQUE와 소유권 검사는 서버에서 원자적으로 수행한다.
