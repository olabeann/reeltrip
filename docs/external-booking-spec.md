# 외부 예약 링크 범위

현재 홈페이지 MVP는 장소 카드의 외부 사이트 링크만 제공합니다. 연결 상품이 확인된 장소는 판매자 페이지로, 그 외에는 방문 정보나 Google Maps로 연결합니다. 예약·결제·변경·취소는 외부 판매자가 처리합니다.

앱 안의 외부 예약 기록 입력·수정·삭제, 예약 번호·금액·메모 저장과 외부 예약 상태 관리는 제외합니다. 링크 클릭을 예약 완료로 표시하지 않으며 가격·재고·예약 가능 여부를 검증 없이 안내하지 않습니다. 제휴 추적·외부 예약 API·웹훅은 미연결입니다.

기존 externalBookings 저장값은 호환성을 위해 보존할 수 있으나 활성 기능이나 신규 데이터 모델 요구사항으로 사용하지 않습니다. 외부 예약과 릴트립 메이트 예약·10% 수수료는 별개입니다.
