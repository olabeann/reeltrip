# 외부 예약 연결 · 공통 기능

1안·릴트립 / 한국어·영어에 동일하게 적용. 실제 예약·결제·취소는 외부 판매자가 처리한다.

## 화면 흐름
- 추출 결과·저장 장소·일정의 장소 카드 → 방문 정보·예약 찾기.
- 상품 연결이 검증된 장소 → 판매자별 상품 페이지. 다른 장소 → 지도 정보 및 Google 사이트 한정 검색.
- N서울타워는 추출 결과와 구분된 별도 추천으로 표시. 선택한 날에 직접 추가할 수 있으며 성수 외 권역임을 안내한다.
- 외부 예약 후 서비스명·방문 날짜·한국 시간·HTTPS 링크·메모를 직접 저장.
- 내 여행에서 전체 기록, 날짜별 일정에서 해당 날짜 기록을 조회. 편집·삭제 제공.

## 정보·표시 정책
- 상품 링크 클릭만으로 예약 완료 처리 금지. 외부 예약 기록은 사용자 입력이며 검증된 예약이 아님.
- 실시간 가격·재고·예약 가능 날짜를 임의 표시하지 않음. 판매자 페이지에서 확인.
- 상품이 연결되지 않은 상태는 예약 불가와 다르게 안내.
- 입력 기록 삭제는 외부 예약 취소가 아님. 앱 내 가이드 예약과 별도 관리.
- 현재 상품별 링크는 수동 관리. 제휴 추적 링크·API·웹훅·예약 완료 자동 수집은 미연동.
- 외부 검색은 Google에서 각 사이트를 검색하는 링크. 각 사업자의 공식 검색 API로 가장하지 않음.
- 저장 데이터는 언어·안별 브라우저 저장 공간에 포함. 외부 예약 메모와 링크는 일정 공유 텍스트에서 제외.
- 링크는 HTTPS만 허용, URL 내 사용자명·비밀번호 차단. HTML 이스케이프. 새 탭 링크에 noopener noreferrer.
- 매장 이름·주소가 수정되면 기존 상품 연결을 해제해 다른 지점으로 잘못 연결되는 것을 방지.
- TikTok·샤오홍슈 영상 분석 지원은 추가하지 않음. 기존 공개 Shorts/Reels 범위 유지.

## 데이터
`externalBookings[]`: id, placeId, placeName, provider, date, time, url, notes, source=user-entered.
예약은 장소별 여러 건 저장 가능. 일정의 장소를 제거하거나 방문 순서를 바꿔도 예약 기록을 자동 취소·삭제하지 않는다.
