홈페이지 문구 기준

현재 상태와 다음 행동

사용자가 지금 확인할 내용과 다음 행동을 짧게 씁니다. 제목은 상태, 설명은 이유, 버튼은 실행을 표현합니다. 내부 역할 ID와 개발 용어를 사용자 문구에 노출하지 않습니다.

예약과 비용

  • 여행자 선택 후에는 메이트 확정 대기, 실제 수수료 결제 검증 후에는 예약 확정으로 표시합니다.
  • 메이트 수수료는 여행 금액의 10%입니다. 여행비는 현장 현금 직접 지급이며 플랫폼 여행비 결제 완료로 표현하지 않습니다.
  • 예약 취소 완료와 수수료 반환 완료를 구분합니다. 반환 접수·검토 단계에서 반환됐다고 안내하지 않습니다.
  • 일행 전체 금액·한국 시간·여행 날짜를 명확히 표시합니다. 현금 지급 시점과 추가 비용은 당사자 합의 사항이며 검증되지 않은 만남 장소를 확정 정보로 쓰지 않습니다.

알림과 가입

이메일 가입에만 광고성 이메일 수신 선택 동의를 기본 미선택으로 표시합니다. 별도 안내 문구는 두지 않습니다. 소셜 신규 가입은 광고 OFF이며 마이에서 변경합니다. 서비스 알림은 사건과 현재 상태가 일치해야 하며 광고 문구를 섞지 않습니다.

장소와 예시

후보 장소·확인된 좌표·영업 정보·외부 예약을 구분합니다. 영상 분석 성공, 실시간 경로, 실제 인증·PG·이메일 완료를 시제품만으로 주장하지 않습니다. 예시와 오류는 사용자의 판단에 필요한 범위에서 안내합니다.
