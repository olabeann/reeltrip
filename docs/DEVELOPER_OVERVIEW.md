# 릴트립 주요 기능 안내

기준일: 2026-11-24. 홈페이지 MVP 개발 공유용입니다. 상세 정책은 이 요약에 중복 작성하지 않습니다.

## 서비스와 흐름

한국을 방문하는 여행자가 장소를 모아 여행을 만들고 현지 메이트의 제안을 비교·선택합니다. 고객·메이트 통합 홈페이지와 계정, 운영자 별도 웹을 사용합니다.

장소 보관 → 여행 생성 → 공개 요청 → 복수 제안 → 여행자 선택 → 메이트 수수료 10% 결제 → 예약 확정. 여행비는 현장 현금 직접 지급이며 플랫폼은 여행비를 수납·정산하지 않습니다.

## 현재 MVP 범위

| 기능 | 포함 범위 |
|---|---|
| 장소·여행 | 보관함과 여행 분리, 복수 여행, 날짜별 장소·순서 편집, 지도·외부 길찾기 |
| 요청·제안 | 전체 여행 일정 또는 자유 여행 요청, 복수 제안, 날짜가 겹치지 않는 복수 요청 |
| 예약 | 선택 후 날짜 확보, 수수료 결제 대기·확정·거절·만료·취소·완료 |
| 채팅 | 확정 이후 양방향 텍스트, 종료 후 읽기 전용, 신고·차단 |
| 마이 | 프로필·메이트 등록·언어·알림·차단·탈퇴 설정 |
| 알림 | 홈페이지 알림함과 이메일 설정, 트리거·발송 주기 운영 제안 |
| 운영 웹 | 심사·재심사·문의·증빙·예약·수수료 반환 기록 |

후기 작성·조회, 가능 날짜 달력, 별도 정산 화면, 외부 예약 기록 양식, 체류시간·방문시각 계산, 앱·브라우저 푸시는 제외합니다. 실제 영상 분석·회원 인증·DB·PG·이메일·다중 사용자 채팅은 미연결입니다. 지도는 설정과 데이터 확인 상태에 따라 실제 연결과 예시를 구분합니다.
