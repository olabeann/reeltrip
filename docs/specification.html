02 규칙과 예외

선택 후 24시간 또는 출발 시각 중 빠른 시각까지 확정. 확정 전 메이트 거절·수수료 결제 기한 만료 시 여행 시작 전이면 자동 재모집. 다른 유효 제안은 즉시 선택 가능하며 새 제안도 접수. 시작 시각이 지났으면 일정 변경 안내. 여행자의 직접 철회·확정 후 취소는 자동 재모집하지 않음.

화면별 명세 기준입니다. 공통 정책과 미확정 사항은 운영 정책 · 개발 인계에서 확인하세요.
