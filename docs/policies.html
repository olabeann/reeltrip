운영 정책

  • 공개 HTTPS Shorts/Reels 링크와 장소 확인을 지원한다. 실제 추출은 미연동이다.
  • 현재 요청 폼은 최소 48시간 전·성수·최대 4시간/6곳·위치 확인 장소를 검사한다. 추가 지역·수동 장소의 권역 판별은 후속 개발이다.
  • 같은 요청에 복수 제안을 보존한다. 동일 메이트의 재발행만 교체하며 고객이 선택한 버전·금액을 예약에 고정한다.
  • 여행자 선택만으로 확정하지 않는다. 선택된 메이트의 매칭 수수료 10% 결제 검증 후에만 확정한다.
  • 현금 수령 상태는 예약 확정·여행 완료와 별개다. 자동 수령 처리하지 않는다.
  • 확정 전 철회와 확정 후 취소 검토를 분리한다. 플랫폼은 여행비 자동 환불을 제공하지 않는다.
  • 수수료 결제 유예시간·노쇼·취소 시 반환·VAT 및 분쟁 정책은 미확정이다. 이전 자동 환불률을 적용하지 않는다.
  • 닉네임 중복 금지: NFKC·공백 제거·소문자 기준. 자신의 기존 이름 유지 허용. 변경 후 재확인과 저장 직전 재검사. 실제 서버 UNIQUE 제약은 별도 구현한다.
