장소와 여행 지도 기준

보관함과 여행

장소 보관함과 여행 일정을 분리합니다. 여행은 최대 7일, 하루 최대 20곳으로 구성하며 날짜·장소 추가/삭제·순서를 편집합니다. 체류시간·방문시각 계산·날짜별 메모·장소를 다른 날짜로 이동하는 기능은 MVP에서 제외합니다.

지도 표시

선택 날짜의 확인된 좌표 전체로 지도 범위를 정하고 목록과 같은 순서로 번호를 표시합니다. 위치가 확인되지 않은 장소도 목록에는 유지합니다. 직선 연결은 방문 순서이며 실제 도보 경로가 아닙니다. 구간별 거리·도보 추정과 Google Maps 길찾기 링크를 구분합니다.

여행 요청

내 여행의 전체 일정 또는 지역·기간을 입력하는 자유 여행 요청을 지원합니다. 요청은 최소 48시간 전이며 최대 7일, 동행은 하루 4시간 기준입니다. 공개 요청·제안·예약에는 전체 날짜와 금액 스냅샷을 유지하고 개인 여행 편집으로 기존 요청을 덮어쓰지 않습니다.

연동 경계

실제 영상 추출은 미연결입니다. 고정 지도 이미지와 예시 좌표는 검증된 Google 장소로 간주하지 않습니다. 추출 작업은 중복 요청 식별자를 사용하고 이름·주소·좌표·출처·확인 상태를 구분해 저장합니다. 지도 키·장소 표시와 출처는 실제 제공자 설정을 따릅니다.
