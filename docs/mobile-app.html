홈페이지 플랫폼과 역할

단일 홈페이지 MVP

고객·메이트는 모바일 화면에 맞춘 하나의 홈페이지와 계정을 사용합니다. 운영자는 별도 웹입니다. 설치형 iOS·Android 앱, 운영체제 공유 수신, 앱·브라우저 푸시는 현재 출시 범위에 포함하지 않습니다.

이용 흐름

장소 보관 → 날짜별 여행 → 공개 요청 → 복수 제안 → 여행자 선택 → 메이트 10% 수수료 결제 → 확정. 여행비는 현장 현금 직접 지급입니다.

여행자 메뉴는 발견 / 내 여행 / 메이트 / 채팅 / 마이, 메이트 메뉴는 여행 찾기 / 내 활동 / 채팅 / 마이입니다. 한국어·영어 홈페이지와 가입 언어 선택을 제공하며 실제 외국어 동행 가능 여부는 메이트 정보와 요청 조건으로 확인합니다.

화면 검수

작은 화면·큰 글자·키보드·뒤로가기·스크린리더·네트워크 오류를 확인합니다. 현재 상태는 브라우저 저장 시연이며 실제 계정 동기화와 결제는 서버 연결이 필요합니다.
