GitHub Pages는 **gh-pages 브랜치 / 루트**에서 배포합니다.
`main`에는 프로젝트 전체를 보관하고 `gh-pages`에는 `reeltrip-planning/` 내용을 사이트 루트로 게시합니다.
변경을 커밋한 뒤 `sh reeltrip-planning/scripts/publish-pages.sh`로 검사·푸시·게시할 수 있습니다.

프로젝트 안내: https://olabeann.github.io/reeltrip/project.html
